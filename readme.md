# Brain Tumor Detection Using Hybrid Deep Learning Model

## Overview
This project implements a **hybrid deep learning model** to detect and localize brain tumors from MRI images. By combining Convolutional Neural Networks (CNNs) with other deep learning techniques (e.g., autoencoders), the model performs **multi-class classification** for tumor types like glioma, meningioma, and pituitary tumors, while highlighting tumor regions for precise localization.

## Features
- Automated **brain tumor detection** from MRI scans  
- **Multi-class classification** of tumor types  
- **Tumor localization** for better visualization  
- High accuracy and robust performance across diverse MRI images  
- Supports **early diagnosis** and aids clinical decision-making  

## Dataset
- The project uses a labeled **brain tumor MRI dataset**  
- Images are preprocessed and augmented to improve model performance  

## Model Architecture
- **CNN layers** for feature extraction  
- **Autoencoder/other deep learning layers** for noise reduction and refined classification  
- Hybrid approach ensures **improved accuracy and localization**
